[被动语态讲解]
① A huge iceberg was suddenly spotted by a
lookout.
② 1,500 lives were lost.
[句型要点与板书（Board Notes）]
为什么要用被动语态？
灾难叙事的绝佳选择：在记叙文中，使用被动语态是为了突出事件本
身，故意弱化动作的发出者。它能带来一种极其冷峻、客观的叙事力
量，让悲剧的压迫感倍增。
今日核心句式提炼：
1. 动名词作主语: The sinking ... will be
remembered.
2. 被动客观叙事：was spotted / were lost（强调事件与悲剧后果）
。

Vocabulary Expansion: Word Formation Magic 掌握
后缀规律，让词汇量成倍增长
后缀 (Suffix) 功能 (Function) 例词推演 (Examples)
-er / -r 表执行者（人） work → worker ; murder → murderer
-ist 表从业者（人） novel → novelist ; violin → violinist
-ness adj. → n. 表状态 happy → happiness ; careless → carelessness
-ion / -ation v. → n. 表动作/结果 translate → translation ; explain → explanation
-ity adj. → n. 表属性 able → ability ; possible → possibility
